FMI Compatibility Information

Note

This page is provided and maintained by the developers of FMI.jl (JuliaFMI). It is not provided by the Modelica Association or the FMI Project.

FMI.jl imports FMUs with FMIImport.jl and creates FMUs with FMIExport.jl. This page summarizes how the FMI support of these packages is validated. All checks listed below run automatically in GitHub Actions on Windows (win64) and Linux (linux64), with the latest Julia release and the Julia LTS release.

FMU Import

FMI Cross-Check (FMI 2.0, ME and CS)

The cross-check workflow imports and simulates the FMI 2.0 FMUs of the FMI Cross-Check repository with FMI.jl and compares the results to the reference results provided by the exporting tools. An FMU passes if the mean normalized root-mean-square error (NRMSE) over all recorded variables is below the threshold set in cross_check_config.jl.

Examples

The examples of this documentation are executed by the examples workflow (Windows, Julia 1.10) with FMI 2.0 FMUs exported by Dymola 2022x (FMUs): BouncingBall1D, IO, SpringFrictionPendulum1D, SpringPendulum1D and SpringPendulumExtForce1D.

Reproducing the Results

  • FMI Cross-Check: see the cross-check README, e.g., run julia --project=cross_checks cross_checks/cross_check.jl --os windows-latest from the root of the FMI.jl repository.
  • Test suites: run using Pkg; Pkg.test("FMIImport") or Pkg.test("FMIExport") in the Julia REPL. The FMUs are downloaded automatically via FMIZoo.jl.
